# Cosplay — Runtime Settings

The `runtime.json` manager ([[Cosplay-Config-Storage]]): auth token, `server_port` (8082), connection/http timeouts, rate limit, `skip_title_generation`.

- Token feeds [[Cosplay-Auth-Token]].
- Port feeds [[Cosplay-FCC-Launcher]] and [[Cosplay-Web-UI]].
- Timeouts feed [[Cosplay-Upstream-Client]].
